# lecture-copilot

강의자료 연동 실시간 음성 인식 기반 강의 보조 프로그램

학생이 교수자의 강의자료(PDF·PPT)를 보면서 수업을 들으면, 프로그램이 수업 음성을 실시간으로 텍스트로 변환하고 강의자료와 연결된 메모를 자동으로 쌓는다. 학생은 수업 중간에 궁금한 점을 바로 질문하고 답변을 받을 수 있으며, 그동안에도 녹음과 메모 생성은 계속된다.

오픈소스기초설계 팀 프로젝트(4인 1팀). 플랫폼: **웹 앱**(브라우저에서 접속, 설치 불필요).

## 팀 & 역할

| 역할 | 담당 | 폴더 | 하는 일 |
|---|---|---|---|
| 1 | 홍성조 | [`frontend/`](frontend/) | 강의자료 뷰어, 녹음 상태, 메모·질의응답 화면 |
| 2 | 김유종 | [`stt/`](stt/) | 녹음 캡처, 음성 인식(STT) 연동, 발화-시간-페이지 기록 |
| 3 | 김찬서 | [`data/`](data/) | 강의자료 파싱, 발화-메모-페이지 연결 구조, 기록 보관·불러오기 |
| 4 | 오서영 | [`rag/`](rag/) | 메모 자동 생성, 질의응답(검색+답변 생성), 근거 표시 |

각 폴더의 자세한 설명은 폴더 안 README.md 참고.

## 폴더 구조

```
lecture-copilot/
├── frontend/   # UI (강의자료 뷰어, 녹음/메모/질의응답 화면)
├── stt/        # 음성 인식 파이프라인
├── data/       # 자료 파싱, 발화-메모-페이지 연결, 저장
├── rag/        # 메모 생성 + 질의응답(RAG)
└── docs/       # 기능 정의서, 회의록 등 문서
```
