# data

담당: 김찬서

강의자료 파싱, 자료-발화-메모 연결, 기록 보관을 담당한다.

## 범위

- PDF·PPT 강의자료를 페이지 단위로 파싱해 텍스트·용어를 추출한다
- 발화(음성 인식 결과)와 메모에 관련 페이지 번호·시간 정보를 연결한다
- 페이지 연결 기준은 **사용자가 뷰어에서 열어둔 페이지**다(교수자가 실제로 설명한 페이지와 달라질 수 있음 — 화면에 이 기준을 드러낼 것)
- 음성 인식 결과가 늦게 도착해도 **실제 발화 당시의 페이지**를 기준으로 연결한다
- 강의자료·발화 기록·자동 메모·질문과 답변을 강의별로 묶어 저장한다
- 다른 강의의 자료·메모가 현재 강의에 섞이지 않게 구분한다

## 연결

- 파싱한 자료는 [`frontend/`](../frontend/)의 뷰어가 표시한다
- 발화 기록은 [`stt/`](../stt/)에서 받는다
- 메모·질문답변 생성에 필요한 자료·기록은 [`rag/`](../rag/)에 제공한다
