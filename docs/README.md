## 아직 확인 안 된 점

기능정의서 검토 중 나온, 팀에서 한 번 맞춰보면 좋을 질문들.

1. **RAG 범위** — 6번 "검색과 답변은 현재 강의의 자료와 기록을 대상으로 한다"고 돼 있는데, 다른 주차/과목까지 검색하는 건 범위 밖이 맞는지
2. **강의자료 없이 시작** — PDF·PPT가 아직 없을 때 녹음만 먼저 시작할 수 있는지
3. **발화자 구분** — 교수자 음성만 대상인지, 주변 소음·다른 학생 목소리도 섞여 들어올 수 있는지
4. **데이터 저장 위치** — 녹음 파일·전사 텍스트를 로컬에만 두는지, 서버로 보내는지(교수자 목소리가 녹음되는 것이라 프라이버시 쪽도 고려)

회의 때 정리되면 이 목록은 지우고 기능정의서에 반영할 것.
