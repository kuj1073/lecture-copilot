# 기능 정의서

> 김유종의 제안서와 사용자가 설명한 이용 방식을 바탕으로 정리한 기능 정의. 팀 Notion 문서를 옮겨온 것 — 원본이 갱신되면 이 파일도 함께 갱신할 것.

수정일: 2026-10-30 (지난주 목요일)

## 1. 프로그램 개요

**강의자료 연동 실시간 음성 인식 기반 강의 보조 프로그램**

학생이 교수자의 강의자료를 보면서 수업을 듣고, 자동으로 쌓이는 메모를 확인하며, 이해하지 못한 부분을 즉시 질문할 수 있는 프로그램이다. 강의자료, 발화 기록, 메모, 질문과 답변을 같은 강의 안에서 연결한다.

강의자료의 용어와 설명을 참고해 음성 인식 결과를 이해하고, 메모와 답변의 근거를 확인할 수 있게 한다. 자료와 실제 발화가 다를 때는 그 차이를 표시한다.

## 2. 주요 기능

| 기능 | 하는 일 | 사용자가 확인하는 결과 |
|---|---|---|
| 강의자료 불러오기·보기 | PDF·PPT 강의자료를 불러와 페이지별로 표시하고 현재 열어둔 페이지를 파악한다 | 강의자료 화면과 현재 페이지 |
| 실시간 녹음·음성 인식 | 수업 음성을 녹음하면서 발화를 순차적으로 텍스트로 변환한다 | 녹음 상태와 계속 추가되는 발화 기록 |
| 실시간 강의 메모 | 인식된 발화와 강의자료를 바탕으로 개념·설명·예시를 정리해 메모를 누적한다 | 수업이 진행되는 동안 갱신되는 강의 메모 |
| 자료·발화·메모 연결 | 발화와 메모에 관련 페이지와 시간 정보를 연결한다 | 메모가 어느 페이지의 어떤 설명에서 나왔는지 확인할 수 있는 근거 |
| 수업 중 질의응답 | 질문과 관련된 자료와 질문 시점까지의 발화 기록을 찾아 답변한다 | 수업 맥락을 반영한 답변과 출처 |
| 기록 보관·다시 보기 | 강의별로 발화 기록, 메모, 질문과 답변을 묶어 보관한다 | 수업 중 또는 수업 후 다시 확인할 수 있는 강의 기록 |

## 3. 기능별 동작

### 강의자료 불러오기·보기

- 사용자가 PDF·PPT 강의자료를 불러온다
- 자료를 페이지 단위로 보여주고 이전·다음 페이지로 이동할 수 있다
- 페이지별 내용을 음성 인식 결과 참고, 메모 생성, 질문 답변의 근거로 활용한다
- 자료 화면을 보면서 녹음 상태, 메모, 질문과 답변을 함께 확인한다

### 실시간 녹음·음성 인식

- 사용자가 녹음을 시작하면 수업 음성을 계속 받아들인다
- 들어오는 음성을 순차적으로 텍스트로 변환하고 발화 시간과 함께 기록한다
- 자료 페이지를 넘기거나 질문을 입력하는 동안에도 녹음을 유지한다
- 녹음을 중지하면 마지막으로 입력된 음성까지 처리하고 기록에 반영한다
- 화면에 녹음 중·음성 처리 중·중지·오류 상태를 표시한다

### 실시간 강의 메모

- 녹음 중에 메모가 계속 생성되고 누적된다
- 새로 인식된 발화를 바탕으로 핵심 개념, 개념에 대한 설명, 교수자가 든 예시 등을 정리한다
- 강의자료에 있는 내용과 수업에서 추가된 설명을 함께 참고한다
- 메모에는 관련 자료 페이지와 발화 시간 또는 발화 구간을 연결한다
- 음성을 텍스트로 옮긴 발화 기록과, 이를 정리한 강의 메모를 구분해 확인할 수 있게 한다
- 용어나 문장의 의미가 불확실하면 확인이 필요한 부분으로 표시하고 원래 발화 기록을 남긴다
- 메모가 갱신되어도 이전에 기록한 수업 내용이 사라지지 않도록 누적한다

메모는 음성 인식 결과와 강의자료를 바탕으로 프로그램이 자동 생성하는 강의 메모를 뜻한다. 생성 결과는 음성 처리와 함께 순차적으로 표시하며, 구체적인 갱신 주기와 허용 지연은 별도 결정 사항이다.

### 자료·발화·메모 연결

- 발화에 해당 시각과 관련 페이지 번호를 기록한다
- 발화에서 만들어진 메모에도 같은 근거를 연결한다
- 사용자가 메모의 페이지나 시간 정보를 선택하면 연결된 자료 또는 발화 기록을 확인할 수 있다
- 음성 인식 결과가 늦게 도착해도 실제 발화 당시의 페이지를 기준으로 연결한다
- 원안의 페이지 연결 기준은 **사용자가 뷰어에서 열어둔 페이지**다. 교수자가 실제로 설명한 페이지와 달라질 수 있으므로 화면에 연결 기준을 드러낸다

### 수업 중 질의응답

- 사용자는 녹음 중 언제든 질문을 입력할 수 있다
- 질문과 관련된 강의자료 페이지를 검색하고, 질문 시점까지 기록된 발화와 최근 수업 맥락을 함께 참고한다
- "방금 말한 개념이 뭐야?", "앞 페이지의 내용과 어떻게 달라?", "교수님이 든 예시를 다시 설명해 줘"와 같은 질문에 답한다
- 답변에는 근거로 사용한 자료 페이지와 발화 구간을 표시한다
- 자료와 발화가 서로 다른 설명을 하면 각각의 근거와 차이를 알려준다
- 확인할 근거가 부족하면 부족하다고 안내한다
- 앞선 질문에 대한 후속 질문도 같은 강의의 대화 맥락 안에서 처리한다
- 질문을 입력하고 답변을 기다리거나 읽는 동안에도 녹음·음성 인식·메모 누적이 계속된다

### 기록 보관·다시 보기

- 강의자료, 발화 기록, 자동 메모, 질문과 답변을 강의별로 묶는다
- 사용자는 녹음 중 앞에서 만들어진 메모를 다시 확인할 수 있다
- 수업 후에도 페이지와 시간을 기준으로 기록을 확인할 수 있다
- 최근 발화만 답변 입력에 사용하더라도, 보관된 전체 강의 기록은 따로 유지한다
- 다른 강의의 자료와 메모가 현재 강의의 답변에 섞이지 않게 구분한다

## 4. 기능 사이의 연결

| 연결 | 전달하는 내용 | 연결 목적 |
|---|---|---|
| 강의자료 → 메모 생성 | 페이지 내용, 용어, 관련 개념 | 발화의 의미를 이해하고 자료에 연결된 메모를 만든다 |
| 녹음·음성 인식 → 메모 생성 | 새 발화 텍스트, 발화 시간 | 수업 진행에 따라 메모를 계속 추가한다 |
| 자료 뷰어 → 페이지 연결 | 페이지 이동 이력 | 발화 당시 어느 페이지를 보고 있었는지 기록한다 |
| 페이지 연결 → 메모·기록 | 페이지 번호와 발화 구간 | 메모의 원래 근거를 다시 찾을 수 있게 한다 |
| 사용자 질문 → 근거 검색 | 질문 내용, 현재 강의, 대화 맥락 | 질문에 필요한 자료와 발화를 선택한다 |
| 근거 검색 → 답변 생성 | 관련 자료 페이지, 발화 기록, 최근 수업 맥락 | 강의 내용에 근거한 답변을 만든다 |
| 메모·질의응답 → 기록 보관 | 누적 메모, 질문, 답변, 출처 | 수업 중과 수업 후에 기록을 다시 확인한다 |

녹음·메모는 수업 진행에 따라 계속 갱신되고, 질의응답은 사용자가 질문할 때 동작한다. 두 기능은 같은 자료와 발화 기록을 활용하면서 동시에 사용할 수 있다. 답변 생성이 지연되더라도 녹음과 메모 누적은 이어진다.

질문 답변은 질문을 받은 시점까지 처리된 발화를 기준으로 만들고, 그 이후 들어오는 수업 내용은 메모에 계속 반영한다. 아직 인식 중인 음성이 있으면 처리 상태를 표시해 사용자가 반영 범위를 알 수 있게 한다.

## 5. 화면 구성과 이용 예시

| 화면 영역 | 표시할 내용 |
|---|---|
| 강의자료 영역 | PDF·PPT 페이지, 현재 페이지 번호, 페이지 이동 |
| 녹음 상태 영역 | 녹음 시작·중지, 녹음 중 표시, 경과 시간, 처리 상태 |
| 메모 영역 | 계속 쌓이는 강의 메모, 연결 페이지·시간, 관련 발화 기록 |
| 질문·답변 영역 | 질문 입력, 답변, 근거 표시, 이전 질문과 답변 |

원안은 왼쪽 강의자료·오른쪽 녹음 및 질의응답 배치에 실시간 메모 표시를 포함한 구성이다.

**예시 상황**

학생이 12페이지를 보면서 강의를 녹음한다. 교수자가 개념과 예시를 설명하면 발화가 텍스트로 기록되고, 관련 내용이 12페이지의 메모에 순차적으로 추가된다.

학생이 "방금 예시는 왜 이 개념에 해당해?"라고 질문한다. 프로그램은 12페이지와 직전 발화를 참고해 답변하고 근거를 표시한다.

답변을 기다리는 동안 교수가 13페이지로 넘어가도 녹음과 메모 생성은 이어진다. 학생은 답변을 확인한 뒤, 그동안 새로 쌓인 13페이지 메모를 읽으며 수업 내용을 확인한다.

## 6. 기능이 동작할 때의 기준

- 발화 기록, 자동 메모, AI 답변을 구분해 실제 수업에서 나온 내용과 생성된 설명의 근거를 확인할 수 있게 한다
- 자료에 적힌 명령문이나 발화 내용을 프로그램 자체의 동작 지시로 실행하지 않는다
- 검색과 답변은 현재 강의의 자료와 기록을 대상으로 한다
- 마이크 입력이나 모델 호출에 오류가 생기면 상태를 표시하고 이미 생성된 기록을 보존한다
- 질문 답변에 필요한 자료와 발화 구간을 선택해 사용한다. 선택 범위와 전체 기록의 보관은 별도로 관리한다
