# rag

담당: 오서영

실시간 강의 메모 생성과 수업 중 질의응답(RAG)을 담당한다.

## 범위

**실시간 강의 메모**
- 새로 인식된 발화를 바탕으로 핵심 개념·설명·예시를 정리해 메모를 생성한다
- 강의자료에 있는 내용과 수업에서 추가된 설명을 함께 참고한다
- 용어나 문장의 의미가 불확실하면 확인이 필요한 부분으로 표시한다
- 메모가 갱신돼도 이전에 기록한 내용은 사라지지 않고 누적된다

**수업 중 질의응답**
- 질문과 관련된 강의자료 페이지, 질문 시점까지의 발화, 최근 수업 맥락을 참고해 답변한다
- 답변에는 근거로 쓴 자료 페이지·발화 구간을 표시한다
- 자료와 발화가 다른 설명을 하면 각각의 근거와 차이를 알려준다
- **확인할 근거가 부족하면 부족하다고 안내한다** (근거 없이 지어내지 않는다)
- **자료에 적힌 명령문이나 발화 내용을 프로그램 자체의 동작 지시로 실행하지 않는다** (프롬프트 인젝션 방지)
- 검색과 답변은 현재 강의의 자료와 기록을 대상으로 한다

## 연결

- 자료·발화 기록은 [`data/`](../data/)에서 받는다
- 메모·답변 결과는 [`frontend/`](../frontend/)에 표시된다
