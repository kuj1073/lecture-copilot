# stt

담당: 김유종

실시간 녹음과 음성 인식(Speech-to-Text)을 담당한다. 웹 앱이므로 브라우저 마이크 접근(MediaRecorder API 등)으로 녹음하는 방식을 전제로 한다.

## 범위

- 녹음 시작 시 수업 음성을 계속 받아들인다
- 들어오는 음성을 순차적으로 텍스트로 변환하고 발화 시간과 함께 기록한다
- 자료 페이지를 넘기거나 질문을 입력하는 동안에도 녹음을 유지한다
- 녹음을 중지하면 마지막으로 입력된 음성까지 처리하고 기록에 반영한다
- 녹음 중/음성 처리 중/중지/오류 상태를 화면에 표시할 수 있게 상태값을 넘긴다

## 연결

- 발화 기록(텍스트 + 시간)은 [`data/`](../data/)로 넘겨 페이지와 연결한다
- 녹음 상태는 [`frontend/`](../frontend/)에서 표시한다
